## Welcome!
This engine is a one-of-a-kind fork, because instead of being forked from an engine like Psych, or Kade, this is built entirely off the Week 6 Update Engine!

## Features
So... what does this engine feature, you may ask? *Well.* Quite a few things, actually.
- Actually Good Input: It was basically impossible to play any song on the Week 6 Engine without dying- COUGH COUGH OLD KADE ENGINE-
- Modular Data: Everything is broken down into parts, like jsons for the characters, stages, and so on.
- Softcoding: SOFTCODING? IN AN FNF ENGINE THATS NOT PSYCH? Yes! This supports `.hxc` files for soft coding events. As of now, only stage scripts are supported.

## Compiling
I've found a way to only have to install about 4GB of crap, instead of the 22GB that the Week 6 Engine uses. You can read about how to actually compile this engine [here.](./docs/Compiling.md)

## Modding
Mod support is massive for an engine like this, since the original Week 6 Engine barely had any support. It was originally going to use Polymod, which was never actually usable. The current guide is [here.](./docs/Modding.md) A wiki is WIP.
